### 🏫 作成背景

大学２年生の夏に参加した **14日間のハッカソン（Hack U）** で４人チームとして制作しました。
社会問題を調査する中で「**保育士の人手不足**」が大きな課題として浮かび上がりました。
そこで、**保育士だけでなく小さなお子さんを持つ家庭の負担を軽減できるアプリ** を作りたいと考え、「ベビCam」を開発しました。

---

### アプリ概要

赤ちゃんをカメラで見守り、小物や危険物を検知した際に通知するアプリ。
保育園や家庭での安心・安全な育児サポートを目的としています。
